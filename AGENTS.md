# Agent Context

tool-agnostic despite the filename, and it contains hard constraints (evidence-citation contract,
no-ownership-attribution rule, read-only MCP surface) that the eval suite enforces.

Shared personal context (global conventions, memory index, cached research) is mapped in
`~/.codex/AGENTS.md`.
